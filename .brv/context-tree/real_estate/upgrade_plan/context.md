# Topic: upgrade_plan

## Overview
Authoritative summary of the RealEstate module upgrade plan, reflecting the final verdict from the Engineering Lead. It prioritizes high-ROI features while deferring over-engineered components.

## Key Concepts
- Phase 1: Engagement (Saved Searches, Inquiries, Appointments, Comparison, Mortgage Calc)
- Phase 2: Agent CRM (SLA, Reminders, Timeline, Notes, Lead Scoring)
- Simplification (Eloquent matching, Computed fields, No AI/ML/Meilisearch)
- Mandatory Requirements (Tenant isolation, Rate limiting, Queue driver, FormRequests)
